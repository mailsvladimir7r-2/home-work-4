# Демонстрація CSS-селекторів та специфічності

## Мета проєкту
Навчальна вебсторінка, створена для наочної демонстрації роботи різних типів CSS-селекторів (тега, класу, атрибута, дочірнього селектора), псевдокласів (`:nth-child`, `:focus`, `:hover`) та правил вирішення конфліктів специфічності.

## Використані технології
* **HTML5** — семантична розмітка сторінки.
* **CSS3** — стилізація елементів та демонстрація каскаду і специфічності.

## Перевірка результату
Сторінку успішно перевірено локально та після публікації на GitHub Pages. Усі приклади селекторів, стани інтерактивної кнопки при наведенні й фокусі через клавішу Tab, а також вирішення конфліктів стилів відображаються коректно.
